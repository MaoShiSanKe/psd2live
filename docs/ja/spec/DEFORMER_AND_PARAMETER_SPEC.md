# デフォーマとパラメータ

[ドキュメント一覧](../../README.md) · [中文](../../zh/spec/DEFORMER_AND_PARAMETER_SPEC.md) · [English](../../en/spec/DEFORMER_AND_PARAMETER_SPEC.md) · [PSD の準備と命名](PSD_LAYER_SPEC.md)

自動生成の標準構成と編集上の約束を説明します。実際の構成は素材・設定・編集によって変わるため、階層ツリー、パラメータパネル、MCP inspect の結果を確認してください。

## 構成

体の根は `DeformBodyXY` で、体自身のパーツ（胴体、服、腕、スカート、尻尾）と頭が回る首だけを覆い、髪や脚は含みません。体 X では腰から上の上半身がひとつの立体として中心線を軸に回り、腰も胸と同じだけ回って、腰回りで回転が消えていきます。胸の前面は回る側へ動き、前に出る肩は少し大きく低く見え、軸に近い首はほとんど動かないので、頭は常に体の中央にあります。体 Y では下向きで肩が少し開き、上向きで背筋が伸びます。体全体は腰とともに動き、体 X では少し横へ、体 Y の下向きでは膝を内に向けて沈み、上向きでは脚が伸びて少し高くなります。その下に `DeformBodyLean`（パラメータ「身体の前後傾」。体は厚みのある立体として三次元で前傾し、透視で描かれます。骨盤が股関節を軸に一部だけ傾いてスカートを運び、上半身が腰で残りを傾けます。前傾では胸と頭が近く、低く、大きくなり、胸の前面は側面より大きく広がり、裾は少し後ろへ引きます。後傾はその逆です。スケルトンがない場合は腕ごとに前後傾を軸とする `DeformArmHang_L/R` もあり、腕は肩から垂れた一体として肩とともに動き拡大し、体と一緒に曲がりません）と `DeformBodyZBreath`（体 Z / 呼吸）があり、さらに頭部回転と頭部追従があります。立っている全身のキャラクターには並列の根 `DeformLegs`（脚）もあり、脚と靴だけを運びます。足はどの体パラメータでも動きません。頭部の下は顔の格子・輪郭・パーツ変位を通じて目眉鼻口耳を制御します。前髪・後ろ髪には独立した追従・物理の枝があります。領域グループ、瞳の形保持・視線、任意の唇などもあるため、固定の古いツリーをプロジェクトの代わりにしないでください。

## 座標とキー形状

画布の左上が原点で、X は右、Y は下です。形状は親の局所空間で評価されます。Warp の正規化座標と Rotation の局所座標は異なります。静止メッシュとキー形状の形式変換は restMeshesToCanvasSpace 等で処理します。

直接の関連付けは対象自身の軸を定め、親の動きは継承されます。キー形状はパラメータ位置での形で、時刻のフレームではありません。モーション・物理はパラメータ値を動かします。新規パラメータだけでは動かず、形との関連付けが必要です。

## 自動変形

頭 X/Y の端点と中点の組み合わせから九姿勢を作り、初期の傾きを局所基準として推定します。顔格子、部分補正、瞳保持、マスク、口耳の処理を使います。脚は股・膝・足首の 2 ボーン IK で曲がり、膝は見る側へ曲がるので正面の太ももは横に振れずに短くなり、1 枚のレイヤーに描かれた脚もそれぞれの膝で曲がります。頭部回転と体に直接下がるスケルトンの回転デフォーマは身体の前後傾を軸に持ち、前傾に合わせて拡縮します。脚を分割して脚ボーンにバインドした場合、メッシュを持つ脚ボーンごとにその下へ体 X/Y を軸とする立ち姿ワープを置き、脚ワープが示す位置へメッシュを運びます。回転デフォーマは支点と角度しか伝えないため、脚ワープの曲げはその下に届きません。傾き・呼吸、髪の頭部追従・物理を分け（体 Z は腰から上を腰を軸に傾け、各行は平行移動のみで幅を保ちます。呼吸は原画の肩と腰の線に合わせて肩とそれに載る頭・腕を持ち上げ、胸を少し広げ、腰から下は動かしません）、まばたきから瞳の形を駆動できます。

これはプリセットであり汎用 3D 復元ではありません。分層・基準点・極端な角度は確認が必要です。曲線定数や分割数は実装を参照し、古い数式を現行の保証として扱わないでください。

## 標準パラメータ

RigParameters に対応します。メッシュ専用、デフォーマ無効、パーツ不足などで実際の集合は変化します。利用者の追加パラメータや差分もあります。

| ID | Range | Default |
| --- | --- | --- |
| `ParamAngleX` | -45…45 | 0 |
| `ParamAngleY`, `ParamAngleZ` | -30…30 | 0 |
| `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ` | -10…10 | 0 |
| `ParamEyeLOpen`, `ParamEyeROpen` | 0…1 | 1 |
| `ParamEyeBallX`, `ParamEyeBallY`, `ParamEyeBallForm` | -1…1 | 0 |
| `ParamBrowLY`, `ParamBrowRY` | -1…1 | 0 |
| `ParamMouthForm` | -1…1 | 0 |
| `ParamMouthOpenY`, `ParamBreath` | 0…1 | 0 |
| `ParamHairFront`, `ParamHairBack` | -1…1 | 0 |

## 検証

初期姿勢、端点、複合角と中間値を確認し、親と局所形状で動きを二重適用していないか調べます。幾何診断と出力再読込は検査であり、全姿勢や公式エディタとの一致の保証ではありません。出力先バージョンによる縮退にも注意してください。
