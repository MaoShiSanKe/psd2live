## 评价标准

| 评价 | 含义 |
| --- | --- |
| 很好 | 稳定完成 |
| 可用 | 完成，需要少量人工修正 |
| 勉强 | 需要大量返工或人工兜底 |
| 不可用 | 未完成，或结果不可接受 |

少量成功样本不代表在其他素材上同样稳定。

## 如何提交新记录

每条记录请包含：

- 应用版本或 commit、宿主、模型；
- 任务描述与源素材，是否使用了图像生成；
- 样本数、返工次数、耗时与额度消耗；
- 结果文件或历史节点，以及明确的通过 / 失败原因。

验收时对照实际模型的中立姿态、参数端点与动态效果，并检查保存重开和导出结果。仅有参考图、工具成功返回或单张截图，不足以证明任务完成。
