# 物理

[项目首页](../../../README.md) · [摇摆生成](SWING.md) · [MCP 使用与接口](../agent/MCP_AUTHORING.md)

物理让参数跟随头部、身体等输入产生惯性摆动。PSD2Live 使用 Cubism 的摆锤模型：一串从根部垂下的节段，输入推动根部或倾斜重力，节段按惯性摆动，指定节段的摆角写入输出参数。导出时写入 `physics3.json` 和 `.cmo3`。

## 物理组从哪里来

模型的所有物理组都列在物理面板里，来源分四种：

| 来源 | 说明 | ID |
|------|------|----|
| 预设 | 按图层自动生成的前发、后发和果冻眼（图层里有对应部件才出现） | `PhysicsHairFront`、`PhysicsHairBack`、`PhysicsEyeJelly` |
| 骨骼 | 骨架第二节以后的尾巴、翅膀的跟随 | `PhysicsSkel_<骨骼 id>` |
| 摆动 | 每个摇摆的每个方向一根摆锤，见[摇摆生成](SWING.md) | `PhysicsSwing_<id>[_X\|_Y]` |
| 自定义 | 在面板或 MCP 中新建 | 默认 `PhysicsCustom<N>` |

生成的组也能直接编辑。编辑后它变成「已修改」，保存的是你的版本，来源（摇摆、骨骼）之后再变化也不会覆盖它；用「恢复生成值」回到生成的版本。每个组都能单独关闭，关闭的组不导出。自定义组如果驱动了某个生成组的输出参数，这个生成组会显示「被替代」，同样不导出。

同一个参数只能由一个生效的组驱动。组无效（参数不存在、没有输入或输出、某参数同时是输入和输出）时列表里标为「无效」，也不导出，编辑区显示原因。

## 物理面板

面板上方是物理总开关和「生效 n / m」计数，以及预览的播放和视线跟随开关，方便边动模型边观察。下面是物理组列表，每行可以勾选启用，标出来源和状态（已修改 / 无效 / 被替代）。

「+ 新建」可以：

- 新建空白摆锤：默认输入头部与身体的晃动，一段长 10，还没有输出；
- 复制所选组为新组（输出参数会清空，避免与原组冲突）；
- 为画布上选中的网格或弯曲变形器创建摆动（进入[摇摆编辑](SWING.md)）。

### 摆锤画布

选中一个组后，编辑区顶部是它的摆锤。实线是实时摆动的摆锤；虚线是它的静止姿态，从实时的根部垂下，每个节点有一个圆环。画面左右镜像显示，所以向右牵动时根部向右移动。

| 操作 | 作用 |
|------|------|
| 在空白处左右拖动 | 像 Cubism Viewer 里横向拖动模型一样牵动模型（只取水平方向），松手后平滑回到原位；根部始终沿顶部横线移动 |
| 上下拖动圆环 | 这一节的长度；单击选中这一节（再次单击取消），下方滑块只调它 |
| 右侧的输出标签 | 标签与它读取的节点同高，连线指向该节点的实时位置，条形显示当前参数值。上下拖动时高亮离它最近的节点，松开即改为取那一段的摆角（即输出行的「摆角取自」） |
| 单击输出标签（或输出行前的色点） | 在摆锤上显示这个输出的范围扇形：这一节相对上一节摆过扇形的角度时，参数从一端走到另一端。拖动扇形边缘的圆点调整范围（即倍率），扇形越窄摆动越明显 |

单击只做选择，拖动超过一小段距离才会修改，避免误改生成的组。悬停或拖动时左上角显示该项的含义和数值。

牵动时，指针位置是目标，模型按 Cubism 的 CubismTargetPoint 以受限的速度和加速度跟过去，再按 CubismLook 的系数换算成角度 X、身体 X 和眼球 X（组里的其他输入参数按拖动量占其半个范围）。实时摆锤播放预览时叠加在预览参数上（包括动作和视线跟随），暂停时叠加在参数面板的值上，所以直接拖参数滑块也能看到反应。右下角按钮让摆锤立即静止。

根部移动范围和重力倾斜范围（输入标准化）在「高级」里设置。

### 响应曲线

摆锤下方的曲线显示这个组对一次标准牵动的反应：向右拉满 1 秒后松开，每个输出一条曲线（按参数范围归一，虚线是参数端点），淡色曲线是牵动量本身。曲线下方列出每个输出的最大幅度和松开后多久静止。调整长度和动力学滑块时曲线随之更新，可以直接比较不同设置的过冲与收敛。

### 节段与动力学

「编辑段」一行选择下方滑块作用的对象：「全部」同时调整所有节段，数字只调整那一节（也可以在画布上单击圆环选择）。它只决定滑块改哪一段，与输出读取哪一段无关。右侧的 +/− 在末端加一节、删除所选节（未选中时删最后一节）。删除节段时，读取它的输出移到上一节，更深的输出跟着上移。

| 滑块 | Cubism 名称 | 效果 |
|------|-------------|------|
| 总长 / 长度 | 振り子の長さ | 越长摆得越慢、幅度越大；选「全部」时按比例缩放所有节段 |
| 摇晃度 | 揺れやすさ（Mobility） | 越大越不容易停下来 |
| 反应速度 | 反応速度（Delay） | 越大对输入反应越快 |
| 收敛速度 | 収束の速さ（Acceleration） | 越大重力越强，越快回到下垂 |

### 输入

每个输入是一个参数和它的影响方式：

- **位移**：参数把摆锤根部左右推动；**角度**：参数倾斜重力方向。
- **影响**：0–100%，参数整个范围映射到标准化范围的比例。
- **⇄**：反转方向。

「+ 添加」列出可用参数，常用的头部、身体角度排在前面；「头部与身体的晃动（标准）」一次加入与头发预设相同的四个输入（角度 X / 身体 X 为位移，角度 Z / 身体 Z 为角度）。

### 输出

每个输出把某一节的摆角写入参数：

- **摆角取自**：选第 k 段时，输出取第 k 节相对上一节的角度（第 1 段相对重力方向），与上面的「编辑段」无关；在画布上把右侧标签拖到某个节点旁松开也能修改。多段摆锤把各段分别接到不同参数上，就能做出甩鞭式的逐段跟随。
- **倍率**：每弧度摆角对应的参数值，结果会被限制在参数范围内；也可以在画布上拖扇形弧端调整。
- **⇄**：反转方向。

输出只有角度类型：Cubism 原生运行时不读取位移类型输出的倍率，这类输出恒为 0。读入的旧数据如有位移类型输出，会提示并可一键改为角度。

「+ 添加」里已被其他生效组驱动的参数显示为不可选，并注明由哪个组驱动。

### 高级

折叠在「高级」下的是画布和滑块已经覆盖、只在需要精确数值时才用的数据：

- 各段数值：每节的长度、摇晃、反应、收敛；
- 输出细节：倍率和权重；
- 输入标准化：位移和角度输入的最小 / 中心 / 最大值。

组名点击即可重命名；「⋯」菜单里有重命名、复制、编辑摆动（摆动来源）、恢复生成值和删除（自定义组）。

每次拖动、滑块拖动或数值输入会在松手后记一条历史，可以撤销。编辑保存在工程里，重建模型后按同样的组重新生成。

## 预览与导出的一致性

面板里的摆锤、响应曲线、内置渲染的软件预览和 MCP 的模拟使用同一个物理引擎，逐项对应 Cubism Native Framework 5-r.5 的 `CubismPhysics::Evaluate`：输入标准化、按 `Fps` 固定步长并在帧间插值输入、组之间通过参数缓存传递（后面的组能读到前面组同一步的输出）、节段更新与空气阻力、输出插值与权重混合，包括 SDK 本身的一些特殊行为。仓库中的 `PhysicsReferenceTest` 用官方 Framework 在导出模型上跑出的逐帧数据（`native/physics_reference`）校验：900 帧不规则帧间隔、链式组、反转、部分权重和位移输出，有无 `Fps` 两种情况下最大偏差约 1e-5。

导出的 `physics3.json` 声明 `Fps: 60`，CMO3 的物理 FPS 也设为 60，摆动不随渲染帧率变化，从 CMO3 经 Cubism Editor 再导出也保持一致。官方 SDK 预览可用时，预览直接由 SDK 读取导出的 `physics3.json`。

物理只写参数；摆动效果取决于输出参数的关键形。自定义组要先为输出参数做好端点形态，否则参数在动但模型不动。

## MCP

`physics` 工具有三种模式（完整字段见 [MCP 使用与接口](../agent/MCP_AUTHORING.md)）：

- `put`：按 ID 新建或修改，只写给出的字段。已有 ID（包括生成的组）以当前组为基础；`inputs` / `outputs` / `segments` 整体替换列表，`length` / `mobility` / `delay` / `acceleration` 作用于所有节段，`output_scale` 作用于所有输出，`segment_count` 改节段数，`enabled=false` 关闭任意组。
- `delete`：删除自定义组，或把已修改的生成组恢复成生成值。
- `simulate`：从静止开始把输入阶跃到给定值、保持 `hold` 秒再放回，返回每个输出在保持期间和松开后的峰值、最终值与稳定时间。

`inspect scope=physics` 列出全部组及来源、是否生效、被谁替代和无效原因。
