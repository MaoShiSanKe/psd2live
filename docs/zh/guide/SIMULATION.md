# 模拟与烘焙

[文档目录](../../README.md) · [物理](PHYSICS.md) · [摇摆生成](SWING.md) · [画布编辑](CANVAS_EDITOR.md) · [MCP 使用与接口](../agent/MCP_AUTHORING.md)

模拟在编辑器里对网格做真实的 2D 布料 / 头发模拟：顶点被固定点牵住，受重力、惯性和碰撞体推动。Cubism 运行时不会做这种模拟，所以**模拟本身不导出**。要导出，须把它**烘焙**成 Cubism 能播放的内容：新参数上的网格关键形，由拟合出的摆锤驱动，另加若干参数上的精确修正。烘焙结果存进工程；重建模型时只写回结果，不会重新模拟。

## 基本流程

1. 在画布上选中裙子或头发的网格，在「模拟」面板点「+ 布料」或「+ 头发」。同一个物理体里的多张网格一起模拟。
2. 指定固定点。可以二选一或同时使用：
   - 切到画布的「模拟」模式，用权重笔刷绘制「固定点」权重组；
   - 在面板「胶水」里把与腰部相连的胶水设为「作为固定点」。
3. 需要碰撞时（如腿顶开裙摆），在画布上选中腿的网格，在「碰撞体」里点「把选中的网格加为碰撞体」。
4. 打开「实时」，在预览里转头、摇身体，调整材质直到效果自然。「试算」给出固定顶点数、静止漂移、最大拉伸和各输入的峰值。
5. 在「烘焙」里点「烘焙」。完成后物理面板出现来源为「模拟」的摆锤组，参数面板出现 `ParamSim…` 参数，导出即包含它们。

列表里每个物理体右侧的小圆点表示是否已烘焙：强调色为已烘焙，警告色为未烘焙（不会导出）。

## 顶点权重组

权重组是每张网格上的逐顶点 0–1 权重，只存在于本软件，不写入 `.moc3` / `.cmo3`。它们在「模拟」模式下用权重笔刷或权重渐变绘制（见[画布编辑](CANVAS_EDITOR.md)），拓扑编辑后按顶点来源插值保留。

| 种类 | 作用 |
| --- | --- |
| 固定点 | 被 Rig 牵住的顶点，权重表示固定得多牢 |
| 碰撞点 | 与碰撞体网格发生碰撞的顶点；没有这个组时所有顶点都参与碰撞 |
| 碰撞体 | 在碰撞体网格上：会把模拟顶点推开的三角形 |
| 刚度 | 逐顶点缩放拉伸和弯曲刚度，用于根部硬、下摆软 |
| 质量 | 逐顶点缩放质量 |
| 阻尼 | 逐顶点缩放阻尼 |
| 受风 | 逐顶点缩放风和力场的作用 |
| 保形 | 逐顶点缩放向原画形状的回弹 |

面板「顶点权重组」为每个种类选用哪个组；未指定时用该种类的第一个组。

## 胶水

胶水不会自动成为固定点，每个与模拟网格相连的胶水在面板里单独选择：

| 角色 | 作用 |
| --- | --- |
| 不参与（默认） | 模拟不理会它，只在运行时焊接 |
| 作为固定点 | 模拟一侧的胶水顶点跟随另一张网格的实际变形，例如裙子与腰部 |
| 双向约束 | 两侧都在模拟中时保持接缝相连，例如分开的前后片 |

## 材质

| 项 | 含义 |
| --- | --- |
| 质量 | 粒子的相对质量 |
| 拉伸 | 抵抗变长的程度；布料和头发应接近 1 |
| 弯曲 | 抵抗弯曲和折叠的程度 |
| 阻尼 | 运动衰减的快慢（每秒） |
| 保形 | 向原画形状回弹的弹簧；0 为纯物理 |
| 余量 | 剧烈甩动时顶点离固定点的距离最多超出静止路径多少 |

模拟开始前会先标定，使原画形状就是静止时的平衡位置，所以打开模拟后静止的模型不会下垂。

## 烘焙

「输入」是晃动物体的参数；为空时使用头部和身体角度（存在的 `ParamAngleX`、`ParamAngleZ`、`ParamBodyAngleX`、`ParamBodyAngleZ`）。烘焙按以下步骤进行：

1. **精确姿态**：对「精确姿态」里的每个参数，把 Rig 摆到它的最小值和最大值，让物体贴着碰撞体静止下来，把与 Rig 的差写成该参数轴上的修正关键形。所以腿抬到哪里，导出的裙子就被顶到哪里。「自动」时取最能移动碰撞体的参数（最多四个）；没有碰撞体时不烘焙精确姿态。
2. **训练动作**：每个输入依次推到最大再放回、推到最小再放回、由慢到快来回摆动，最后所有输入一起动。每帧记录物体与 Rig（加上精确姿态修正）之差，换算到各网格自己的关键形坐标。
3. **摆锤**：用 Nelder–Mead 拟合一根 Cubism 摆锤 `PhysicsSim_<id>`，节数等于「模态数」（1–3）。搜索的量包括各节摆长与反应速度、摇摆度、收敛速度、各输入的影响度与方向。评价标准是各节角度的线性组合能解释多少记录下的运动；计算与导出一致，多节摆锤的后一节自然落后于前一节，形成甩鞭式的延迟。
4. **模态参数**：摆锤第 k 节的角度写入 -1…1 的参数 `ParamSim<id>_<k>`（输出倍率使该节 98% 的摆动落在 ±1 内）。每个参数在 -1、-0.5、0、0.5、1 上各有一个关键形，取训练中摆锤把该参数带到这个值附近的各帧的平均形状（先减去其他节的贡献），因此弧形摆动和单侧被推开的形状得以保留。几乎不动的节不生成参数。

烘焙完成后面板显示每个参数的摆幅、摆锤与模拟的拟合 R² 以及关键形与模拟的差距。R² 低于 0.8 以警告色显示，通常说明输入选得不对，或运动过于复杂，需要增加模态数。

烘焙后的摆锤组和普通生成组一样，可以在物理面板里查看、修改或关闭。

### 过期

烘焙记录了它所依据的设置、目标网格、权重组、相关胶水和碰撞体网格。它们变化后，面板提示烘焙已过期。过期的烘焙仍会导出，点「重新烘焙」更新；「清除烘焙」会移除它的参数、关键形和摆锤。目标网格被重建（顶点数变化）时，该网格的烘焙结果跳过并在面板中提示。

### 实时预览与烘焙结果

打开「实时」时画布显示真实模拟，此时该物理体自己的 `ParamSim…` 参数保持静止，不会叠加两次；关闭「实时」后预览播放的就是导出的烘焙结果，可以两者对照调整。

## MCP

`simulation` 工具：

- `put`：按 `id` 新建或局部修改物理体，字段包括 `targets`、`material`、`groups`、`glue_roles`、`colliders`、`inputs`、`modes`、`static_inputs`；
- `simulate`：只读试算，返回峰值、静止漂移、拉伸和设置提示；
- `bake`：烘焙（较慢），返回各模态参数与摆幅、摆锤 ID 与节数、拟合 R² 和误差；
- `clear_bake`：清除烘焙；
- `delete`：删除物理体。

`vertex_group` 工具按规则（`fill`、`outline`、`gradient`、`glue`、`region`）生成或删除权重组，不传逐顶点数组。`inspect scope=simulations` 列出物理体、胶水键和烘焙摘要（含 `bake_stale`），`scope=vertex_groups` 列出权重组。

- 已实现：布料与头发（XPBD 求解，固定点、胶水角色、长程约束、网格碰撞体）、顶点权重组、实时预览、烘焙为参数 + 关键形 + 摆锤并导出。
- 已有单元测试：烘焙生成参数、关键形轴与生效的摆锤组；在阶跃输入下，烘焙模型的发梢轨迹与模拟相符；重建结果不变、过期判定、工程 JSON 往返。
- 尚未实现：风等力场导出、刚体与软体、烘焙为普通关键（去掉生成器）。
- 尚待实测：示例模型上的裙子与头发导出后在官方运行时中的视觉效果。
