# 模拟与烘焙

[文档目录](../../README.md) · [物理](PHYSICS.md) · [摇摆生成](SWING.md) · [画布编辑](CANVAS_EDITOR.md) · [MCP 使用与接口](../agent/MCP_AUTHORING.md)

模拟在编辑器里对网格做真实的 2D 布料 / 头发模拟：顶点被固定点牵住，受重力、惯性和碰撞体推动。Cubism 运行时不会做这种模拟，所以**模拟本身不导出**。要导出，须把它**烘焙**成 Cubism 能播放的内容：新参数上的网格关键形，由拟合出的摆锤驱动，另加若干参数上的精确修正。烘焙结果存进工程；重建模型时只写回结果，不会重新模拟。

## 基本流程

1. 在画布上选中裙子或头发的网格，在「模拟」面板点「+ 布料」或「+ 头发」。同一个物理体里的多张网格一起模拟。
2. 指定固定点。可以二选一或同时使用：
   - 切到画布的「模拟」模式，用权重笔刷绘制「固定点」权重组；
   - 在面板「胶水」里把与腰部相连的胶水设为「作为固定点」。
3. 需要碰撞时（如腿顶开裙摆），在画布上选中腿的网格，在「碰撞体」里点「把选中的网格加为碰撞体」。
4. 切到「参考模拟」，在预览里转头、摇身体，调整材质直到效果自然。「试算」给出固定顶点数、静止漂移、最大拉伸和各输入的峰值。
5. 「自动烘焙」默认开启：在面板里的每次修改都会在同一步撤销内重新烘焙。也可以在「烘焙」里手动点「烘焙」。烘焙后物理面板出现来源为「模拟」的摆锤组，参数面板出现 `ParamSim…` 参数，导出即包含它们。
6. 切回「导出效果」，预览播放的就是导出模型的动作，与参考模拟对照。

列表里每个物理体右侧的小圆点表示是否已烘焙：强调色为已烘焙，警告色为未烘焙（不会导出）。

## 顶点权重组

权重组是每张网格上的逐顶点 0–1 权重，只存在于本软件，不写入 `.moc3` / `.cmo3`。它们在「模拟」模式下用权重笔刷或权重渐变绘制（见[画布编辑](CANVAS_EDITOR.md)），拓扑编辑后按顶点来源插值保留。

| 种类 | 作用 |
| --- | --- |
| 固定点 | 被 Rig 牵住的顶点，权重表示固定得多牢 |
| 碰撞点 | 与碰撞体网格发生碰撞的顶点；没有这个组时所有顶点都参与碰撞 |
| 碰撞体 | 在碰撞体网格上：会把模拟顶点推开的三角形 |
| 刚度 | 逐顶点缩放拉伸和弯曲刚度，用于根部硬、下摆软 |
| 质量 | 逐顶点缩放质量 |
| 阻尼 | 逐顶点缩放阻尼 |
| 受风 | 逐顶点缩放风和力场的作用 |
| 保形 | 逐顶点缩放向原画形状的回弹 |

面板「顶点权重组」为每个种类选用哪个组；未指定时用该种类的第一个组。

## 胶水

胶水不会自动成为固定点，每个与模拟网格相连的胶水在面板里单独选择：

| 角色 | 作用 |
| --- | --- |
| 不参与（默认） | 模拟不理会它，只在运行时焊接 |
| 作为固定点 | 模拟一侧的胶水顶点跟随另一张网格的实际变形，例如裙子与腰部 |
| 双向约束 | 两侧都在模拟中时保持接缝相连，例如分开的前后片 |

## 材质

| 项 | 含义 |
| --- | --- |
| 质量 | 粒子的相对质量 |
| 拉伸 | 抵抗变长的程度；布料和头发应接近 1 |
| 弯曲 | 抵抗弯曲和折叠的程度 |
| 阻尼 | 运动衰减的快慢（每秒） |
| 保形 | 向原画形状回弹的弹簧；0 为纯物理 |
| 余量 | 剧烈甩动时顶点离固定点的距离最多超出静止路径多少 |

模拟开始前会先标定，使原画形状就是静止时的平衡位置，所以打开模拟后静止的模型不会下垂。

## 烘焙

「输入」是晃动物体的参数；为空时使用头部和身体角度（存在的 `ParamAngleX`、`ParamAngleZ`、`ParamBodyAngleX`、`ParamBodyAngleZ`）。

### 设置

| 项 | 含义 |
| --- | --- |
| 模态数（1–3，默认 1） | 生成几个参数，每个由拟合摆锤的一个顶点驱动。长发束、飘带这类会甩出鞭梢的物体用 2–3 个更贴近；普通头发和裙子 1 个最均衡，参数也最少 |
| 关键点（3 / 5 / 7 / 9） | 每个模态参数和每个精确姿态参数上的关键点数，均匀分布。越多越能贴合弧线和推挤，增加的是关键形而不是参数 |
| 夸张（×1–×2，默认 ×1.3） | 模态摆动比模拟大多少。写回关键形时生效，改了立即起作用，不需要重新烘焙，也不会让参数顶到极值。二次元风格通常比真实略大更好看 |
| 精确姿态 | 在自己的轴上烘焙成精确修正的参数；「自动」时取最能移动碰撞体的参数（最多四个） |
| 模态写成 | 「自动」（默认）、「融合变形」或「关键形轴」。两种写法播放效果相同。关键形轴所有 Cubism 版本都能读，但每个模态会把网格的关键形数量乘以它的关键点数；融合变形（Cubism 4.2+）的关键形叠加在原有关键形上。「自动」只在某张目标网格的关键形会超过 64 个时用融合变形；目标版本不支持时一律写成关键形轴 |
| 自动烘焙 | 默认开启。本面板或 MCP `put` 的每次修改都在同一步撤销内重新烘焙，并从上次的摆锤出发搜索，比从头烘焙快 |

融合变形省下的是关键形，不是参数：例如一张网格原本有 9 个关键形，2 个模态、各 5 个关键点，写成关键形轴是 9 × 5 × 5 = 225 个，写成融合变形是 9 个加 8 个融合形。

### 步骤

1. **精确姿态**：把 Rig 摆到每个精确姿态参数的各个关键点，让物体贴着碰撞体静止下来，把与 Rig 的差写成该参数轴上的修正关键形。所以腿抬到哪里，导出的裙子就被顶到哪里。没有碰撞体时「自动」不烘焙精确姿态。
2. **动作库**：按实际操作模型的方式驱动各输入，并且用满它们的范围：每个输入单独快速转到两端再停住（看甩出和回摆），像鼠标拖动那样每 0.3–1.2 秒在 0.1–0.3 秒内跳到新姿态，0.7–2 Hz 左右来回摇，从慢到快全幅来回甩（逼近物体的共振），缓慢的闲置摇摆，以及它们的混合。每一段都从静止开始，在各自的物体副本上并行模拟。每帧记录物体与 Rig（加上精确姿态修正）之差，换算到各网格自己的关键形坐标。另有一段同类但种子不同的动作只用来检验。各段按运动量均衡计权，幅度大的全幅甩动不会压过其他动作。
3. **摆锤**：拟合一根 Cubism 摆锤 `PhysicsSim_<id>`，节数等于模态数。评分看整体效果而不只是误差：跟随模拟的程度，输入停下后甩出和回摆的程度（单独再计一次），以及每一段动作里是否比模拟更抖。各输入的类型（X 平移或角度）和初始影响度由小幅叠加的最小二乘估出，之后 Nelder–Mead 同时搜索各节的摆长、反应速度、摇摆度、收敛速度和各输入的影响度；每个候选都用与导出一致的计算、按真实幅度把整个动作库播放一遍再评分。几个候选里，在检验动作上得分最好的胜出。
4. **模态参数**：摆锤第 k 个顶点的角度写入 -30…30 的参数 `ParamSim<id>_<k>`。输出倍率按摆锤在整个动作库（含最剧烈的全幅甩动）中的最大摆角再留 10% 余量来定，所以参数不会顶到 ±30：参数停在极值时头发会停住，看起来就是卡顿。参数范围取 ±30 而不是 ±1，是因为关键形轴会把离关键点 0.001 以内的值吸附到关键点上（Cubism 运行时也如此），在 ±1 的范围里，大物体每次摆过静止位置都会被这一下吸附顿一下。
5. **关键形**：所有模态的所有关键形按最小二乘一起求解：每帧的形状等于各参数在摆锤播放值处的关键形插值之和。关键形被约束在一条平滑的曲线上，相邻关键点处不拐急弯，静止关键点处直线穿过，否则参数扫过关键点时速度突变，也是一种顿挫。几乎不动的参数不生成。

烘焙完成后面板显示（均在检验动作上测得）：每个参数的摆幅、与模拟的 R²、95% 的帧与模拟的最大偏差、模态参数最多用到范围的多少、顶到极值的帧占比，以及急动度与模拟之比（1 为一样平滑），另有模态的写入方式。R² 低于 0.8、有帧顶到极值或急动度超过 1.5 倍时以警告色显示。

烘焙后的摆锤组和普通生成组一样，可以在物理面板里查看、修改或关闭。

### 效果与耗时

tml 示例后发（792 个顶点，顶部十分之一固定），夸张 ×1，关键形轴写法。在两段烘焙时没有出现过的动作上，逐帧对比参考模拟与导出模型（Cubism 摆锤 + 关键形）：「转头」为头部快速左右转头、停住再加小幅摇晃；「拖动」为头和身体每 0.4–1.2 秒被拖到随机姿态。粗糙度是位移的三阶差分与一阶差分之比，越小越平滑，参考模拟为转头 0.075、拖动 0.267。

| 设置 | 转头 R² | 转头粗糙度 | 拖动 R² | 拖动粗糙度 | 拖动摆幅 / 模拟 | 顶到极值的帧 | 烘焙耗时 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 模态、5 关键点（默认） | 0.88 | 0.058 | 0.53 | 0.231 | 0.60 | 0 | 约 3 秒 |
| 2 模态、5 关键点 | −0.18 | 0.072 | 0.60 | 0.232 | 0.62 | 0 | 约 4.5 秒 |
| 2 模态、7 关键点 | −0.17 | 0.083 | 0.61 | 0.237 | 0.63 | 0 | 约 3.5 秒 |

- 两种动作下导出结果都不比参考模拟粗糙，参数都没有顶到极值。
- 这一束后发上，2 模态的第二个模态在小幅动作中与第一个相互抵消，转头时几乎不动，所以默认用 1 模态；长而会甩出鞭梢的发束（单元测试里的细长发束）2 模态更好。
- 拖动时导出的摆幅约为模拟的六成，默认的夸张 ×1.3 把它补回大部分。

耗时在 32 线程的台式机上测得；训练与拟合在多核上并行，核数少时会更慢。上表由 `SimBakeBenchmark` 生成：`PSD2LIVE_BENCH=1 ./gradlew test --tests "*SimBakeBenchmark"`，`BAKE_CONFIGS=1:5,2:5` 指定设置。

### 过期

烘焙记录了它所依据的设置、目标网格、权重组、相关胶水和碰撞体网格。它们变化后，面板提示烘焙已过期。开启自动烘焙时，面板和 MCP 里的修改会立即重新烘焙；在别处做的修改（网格、权重）仍会显示过期。过期的烘焙仍会导出，点「重新烘焙」更新；「清除烘焙」会移除它的参数、关键形和摆锤。自动烘焙失败或被取消时保留旧的烘焙并提示原因。目标网格被重建（顶点数变化）时，该网格的烘焙结果跳过并在面板中提示。

### 导出效果与参考模拟

面板顶部和画布「模拟」模式的工具条可以切换预览内容：

- **导出效果**：预览播放烘焙结果，即由拟合的 Cubism 摆锤驱动的参数和关键形，与导出的模型动作一致。未烘焙的物体在这里不动，画布左下角提示「有未烘焙的模拟」。
- **参考模拟**：画布显示编辑器自己的物理模拟，只用来对照，不会导出。画布左下角以警告色标明「参考模拟 · 不会导出」，此时该物理体自己的 `ParamSim…` 参数保持静止，不会叠加两次。

## MCP

`simulation` 工具：

- `put`：按 `id` 新建或局部修改物理体，字段包括 `targets`、`material`、`groups`、`glue_roles`、`colliders`、`inputs`、`modes`、`keys`、`exaggeration`、`static_inputs`、`blend_shapes`（`true` / `false` / `null` 为自动）、`auto_bake`；`auto_bake` 开启（默认）时在同一步内重新烘焙，并返回 `bake` 摘要或 `bake_error`；
- `simulate`：只读试算，返回峰值、静止漂移、拉伸和设置提示；
- `bake`：烘焙（2–5 秒），返回各模态参数与摆幅、关键点数、摆锤 ID 与节数，以及在检验动作上的 `fit_r2`、`error_p95_px`、`parameter_peak`（模态参数最多用到范围的比例）、`clipped_frames`（顶到极值的帧占比）与 `jerk_ratio`（急动度与模拟之比）；
- `clear_bake`：清除烘焙；
- `delete`：删除物理体。

`vertex_group` 工具按规则（`fill`、`outline`、`gradient`、`glue`、`region`）生成或删除权重组，不传逐顶点数组。`inspect scope=simulations` 列出物理体、胶水键和烘焙摘要（含 `bake_stale`），`scope=vertex_groups` 列出权重组。

## 当前范围

- 已实现：布料与头发（XPBD 求解，固定点、胶水角色、长程约束、网格碰撞体）、顶点权重组、参考模拟预览、烘焙为参数 + 关键形（融合变形或关键形轴，可自动选择）+ 摆锤并导出、自动烘焙、夸张系数。
- 已有单元测试：烘焙生成融合变形参数与生效的摆锤组，融合变形与关键形轴两种写法结果一致；在快速转头并停住时，烘焙模型的发梢轨迹与模拟相符；全幅来回甩头时模态参数不顶到极值，导出结果不比模拟更抖；动作库覆盖各输入的全范围且每段从静止开始；夸张系数按比例放大写回的位移且不需要重新烘焙；「自动」写法按关键形数量选择；关键形最小二乘解、关键点数设置、自动烘焙只在过期时重算；重建结果不变、过期判定、工程 JSON 往返；tml 后发烘焙后导出的 `physics3.json` 与 `.moc3` 含对应摆锤和参数。
- 实测：上表 tml 后发的对比数据。
- 尚未实现：风等力场导出、刚体与软体、烘焙为普通关键（去掉生成器）。
