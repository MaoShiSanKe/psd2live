# 操作速查

[文档目录](../../README.md) · [English](../../en/guide/USER_GUIDE.md) · [日本語](../../ja/guide/USER_GUIDE.md)

先打开 **帮助 → 教程…**（`F1`）。交互教程会高亮控件、切换到相关面板，并按你当前的快捷键提示操作；本文是它的文字版，用于回看，不逐个讲解按钮。

## 最短流程

导入 PSD（`Ctrl+Shift+O`）→ 检查图层分类与预览 → 按需编辑 → 保存工程（`Ctrl+S`）→ 导出（`Ctrl+G`）。已有 `.psd2live` 用 `Ctrl+O` 打开。

## 工作区

界面由顶部的工作区标签组成，每个标签有自己的画布与面板布局。点标签栏右侧的 **+** 新建工作区，可选七种预设或空白布局，右侧会预览布局与用途：

![新建工作区菜单](../../imgs/workspace-presets.webp)

| 预设 | 用途 |
| --- | --- |
| 编辑 | 一块编辑画布，处理变形器、关键形和骨骼，属性面板齐全 |
| 网格 | 层级树、编辑画布与网格面板，编辑网格拓扑 |
| 绑定 | 编辑画布与实时预览并排，参数面板常驻 |
| 动画 | 动作列表、预览画布与动画编辑器 |
| 预览 | 大尺寸预览，只保留动作列表 |
| 物理 | 预览画布加参数与物理面板，边牵动模型边调整 |
| 历史 | 只有历史树和它的操作列表，浏览与切换历史 |
| 空白 | 空的停靠区，从 **窗口** 菜单添加需要的画布和面板 |

**重置布局** 恢复当前工作区的预设布局。

## 按交互教程学习

教程目录共有 18 个主题：零基础路线包含下列 17 课；有 Cubism 经验的路线会先读一章术语对照，再跳过部分入门课。

| 课 | 主题 | 操作要点 |
| --- | --- | --- |
| 1 | 基础流程 | 导入分层 PSD，检查预览、图层预设和模型设置，再选择导出格式。 |
| 2 | 工作区导览 | 编辑页改模型，预览页看效果，历史页切版本；每个画布标签页独立保存镜头和视图开关。 |
| 3 | 层级树与模式条 | 在树中选择、搜索或改父级；透明图片可拖入树中，放置确认后成为图层。绘制顺序决定遮挡，父级决定继承形变。 |
| 4 | 图层类型与差分 | 「预设」使用部件算法；「开关差分」用一个参数控制有无；「切换差分」用同一参数及不同关联 ID 实现多选一。 |
| 5 | 参数与关键形 | 拖滑块或 XY 控件检查姿态；右键参数键标记吸附。先确定目标参数值，再编辑关键形。 |
| 6 | 选择模式 | 选择对象，利用框选、套索和树画布联动定位；只选对象，不修改几何。 |
| 7 | 创建变形器 | 选目标 → 树右键添加父级或子级变形器 → 调整放置预览 → 确认。 |
| 8 | 变形模式 | 调整当前姿态的控制点、整体变换或形变笔刷；注意当前 L1 / L2 编辑层级。 |
| 9 | 编辑模式 | 修改网格拓扑，例如细分、连接、切割与删除；完成后复查参数姿态。 |
| 10 | 绘画模式 | 先选图层，再用画笔、橡皮、填充等修像素；会话内独立撤销，完成后应用或放弃。 |
| 11 | 检视面板 | 根据所选对象修改名称、归属、遮罩、绘制顺序、透明度与颜色等属性。 |
| 12 | 工具细节 | 调整当前工具的半径、硬度、强度、形状等；右键菜单也随模式和工具变化。 |
| 13 | 骨骼绑定与姿态 | 创建骨链、绑定画元，检查权重平滑扩散与 IK，并在面板配置参数采样容差与关键形上限。导出时烘焙为 Cubism 参数、变形器与关键形。 |
| 14 | 动画与动作编辑器 | 在时间线上编辑参数轨道与关键帧，支持自动插帧、默认贝塞尔缓动、轨道关键帧标记与多画布姿态共享。 |
| 15 | 物理画布调试 | 设置输入、摆锤与输出，用范围和实测最大值校准输出倍率。 |
| 16 | 工程与历史 | 保存 `.psd2live`，在紧凑历史树中搜索节点、高亮分支或双击快速检出；支持独立「历史」工作区预设。 |
| 17 | 贴图高清化 | 配置本地后端，选择 2× / 4×；检查边缘、半透明部件和导出结果。 |

## 容易混淆的概念

- **保存与导出**：保存保留工作区和历史；导出生成目标软件使用的模型文件。`.psd2live.json` 是报告，不是工程。
- **关键形与关键帧**：参数键上的关键形属于建模，键之间会插值出模型形状；关键帧位于动画时间线，记录某个时刻的参数值。
- **变形与编辑**：变形改变形状；编辑改变控制网格的结构。绘画修改像素，采用独立的应用 / 放弃会话。
- **显隐与差分**：树中的临时独显、图层静态显隐用于编辑检查；需要随参数切换时，设置差分或不透明度关键形。

## 常用快捷键

以下为默认（Photoshop 风格）键位。**设置**中可切换为 Blender 或 Cubism 风格预设，也可逐项自定义；**帮助 → 快捷键…** 显示当前绑定。

| 操作 | 默认键位 |
| --- | --- |
| 打开工程 / 导入 PSD | `Ctrl+O` / `Ctrl+Shift+O` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` |
| 导出模型 / 导出 PSD | `Ctrl+G` / `Ctrl+Shift+E` |
| 重新分析 PSD | `Ctrl+R` |
| 纹理高清化 | `Ctrl+U` |
| 教程 | `F1` |
| 缩放 / 平移画布 | 滚轮 / 中键拖动或空格 + 左键 |
| 适配所选对象 / 重置镜头 | `F` / `Home` 或 `0` |
| 临时选择 / 快速预览切换 | 按住 `Z`，松开恢复 / 反引号键（Esc 下方） |
| 确认 / 取消当前操作 | `Enter` / `Esc`，具体以当前工具提示为准 |

## 检查与排错

| 现象 | 先检查 |
| --- | --- |
| 部件动作不对或没有动作 | [图层命名](../spec/PSD_LAYER_SPEC.md)与「图层」表格中的类型、侧别；遮罩与父级 |
| 静态姿态正常，运动时穿帮 | 在动画或物理面板中播放检查；单个静态姿态不能代表完整运动 |
| 面板不见了 | 「窗口」菜单中的面板开关，或右上角「重置布局」 |
| 画布上看不到模型 | 先适配画布（`F` / `Home`），再检查图层显隐 |
| 导出失败或提示降级 | 日志面板与导出报告 `.psd2live.json`，以及导出目标版本 |

提交问题时请附版本、操作系统、复现步骤及相关素材。
