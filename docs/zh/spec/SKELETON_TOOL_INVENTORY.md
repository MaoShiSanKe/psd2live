# 骨骼模式工具盘点

[骨骼操作指南](../guide/SKELETON.md)

## 当前能力

骨骼模式包含「姿态」和「骨骼编辑」两个主工具。骨骼编辑包含 3 个子工具：编辑、新骨骼、挤出。子工具切换保留同一草稿，完成或离开编辑时作为一次历史记录保存，取消放弃草稿。

| 区域 | 已有操作 | 当前边界 |
| --- | --- | --- |
| 编辑 | 点选骨骼、拖动关节、相连关节同步移动 | 单骨骼选择；没有整骨平移、旋转、缩放 |
| 新骨骼 | 拖拽创建独立自定义骨骼，显示预览并自动选中 | 不设置父级，不自动继承网格绑定 |
| 挤出 | 从选中骨骼末端延伸子骨骼，支持连续挤出 | 每次创建一根自定义骨骼 |
| 树操作 | 默认长度添加、删除并将子骨骼挂到原父级、尾巴和翅膀开关 | 身体骨骼受删除保护；没有通用父级编辑 |
| 绑定 | 点击网格绑定，树中解除绑定，绑定颜色预览 | 每个网格只指定一个绑定骨骼；肢体内部自动计算权重 |
| 关节设置 | 关节带宽、最小和最大角度 | 带宽控制自动权重过渡；没有手工顶点权重绘制 |
| 姿态 | 拖动骨骼身体进行 FK，拖动末端或按 Shift 进行 IK，重置姿态 | IK 最多影响两级父骨骼；没有独立求解器设置 |
| 权重显示 | 按骨骼颜色显示蒙皮权重 | 仅显示 |
| 骨架管理 | 自动推断、启用和禁用、草稿完成和取消 | 一个工程一套骨架 |
| 采样与动作 | 采样容差、角度间隔、关键形上限、骨骼预设动作 | 属于骨骼面板和动画面板能力 |

## 可添加工具：16 项

按结构编辑 8 项、绑定与权重 4 项、姿态 4 项统计。优先级建议为 P0 5 项、P1 7 项、P2 4 项；这些是待实现建议，不代表当前已支持。

| 类别 | 工具 | 优先级 | 建议行为 |
| --- | --- | --- | --- |
| 结构 | 多选与变换 | P0 | 框选、增选，整骨或骨链平移、旋转、缩放，明确相连关节的联动范围 |
| 结构 | 重命名 | P0 | 修改显示名称，保持 ID、参数和绑定引用稳定 |
| 结构 | 设置／清除父级 | P0 | 选父骨骼，检查循环，选择保持位置或连接末端 |
| 结构 | 复制骨骼／骨链 | P1 | 新 ID，保留层级和关节设置，明确是否复制绑定 |
| 结构 | 镜像骨骼／对称编辑 | P1 | 设置对称轴，镜像坐标、侧别和方向，匹配左右图层 |
| 结构 | 细分骨骼 | P1 | 将一根骨骼分成多节，迁移子级并重新计算绑定影响 |
| 结构 | 融合／溶解骨骼 | P1 | 合并骨段并迁移网格绑定，区分于当前删除后重挂子级 |
| 结构 | 连接／断开关节 | P2 | 保留父级关系，控制端点是否联动；需要显式连接状态，避免仅靠坐标判断 |
| 绑定与权重 | 批量绑定 | P0 | 多网格绑定到选中骨骼，提供确认前的绑定预览 |
| 绑定与权重 | 权重绘制／平滑 | P1 | 顶点权重增减、替换和平滑；先扩展权重存储与烘焙读取 |
| 绑定与权重 | 权重归一化／清理 | P1 | 清理低权重、限制影响骨数量、检查无权重顶点，配合手工权重 |
| 绑定与权重 | 权重复制／镜像 | P2 | 用位置或拓扑匹配顶点，明确未匹配顶点处理方式 |
| 姿态 | 显式 FK／IK 子工具 | P0 | 将现有身体／末端拖拽语义显式展示，保留快捷操作 |
| 姿态 | 保存／应用姿态 | P1 | 保存命名参数快照，在动画面板插入或应用 |
| 姿态 | IK 固定目标 | P2 | 固定手脚目标，编辑父级时持续求解，保存目标和链长 |
| 姿态 | 约束与求解器设置 | P2 | 设置 IK 链长、弯曲方向和旋转约束，说明烘焙与导出行为 |

## 实施顺序

先完成结构操作的选中状态、草稿及撤销语义，再做重命名、父级设置、多选变换和批量绑定。显式 FK／IK 可复用现有姿态求解逻辑。复制、镜像、细分和融合需要同步验证参数 ID、绑定网格与导出；手工权重需要先建立持久化数据和统一的运行时／烘焙读取路径。IK 目标和约束最后加入。
