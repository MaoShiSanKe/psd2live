# 骨骼模式工具盘点

[骨骼操作指南](../guide/SKELETON.md)

## 当前能力

骨骼模式包含「姿态」和「骨骼编辑」两个主工具。骨骼编辑包含 3 个子工具：编辑、新骨骼、挤出。子工具切换保留同一草稿，完成或离开编辑时作为一次历史记录保存，取消放弃草稿。

| 区域 | 已有操作 | 当前边界 |
| --- | --- | --- |
| 编辑 | 单选、Shift 增减选、框选、骨链选择、平移／旋转／缩放、拖动关节 | 外部连接端点同步；可选择变换包含后代 |
| 新骨骼 | 拖拽创建独立自定义骨骼，显示预览并自动选中 | 不设置父级，不自动继承网格绑定 |
| 挤出 | 从选中骨骼末端延伸子骨骼，支持连续挤出 | 每次创建一根自定义骨骼 |
| 树操作 | 默认长度添加、删除并将子骨骼挂到原父级、尾巴和翅膀开关、重命名、设置／清除父级、连接／断开关节 | 父级设置过滤自身和后代；连接会平移子树，断开保留位置；身体骨骼受删除保护 |
| 绑定 | 点击网格绑定，树中解除绑定，绑定颜色预览 | 每个网格只指定一个绑定骨骼；肢体内部自动计算权重 |
| 关节设置 | 关节带宽、最小和最大角度 | 带宽控制自动权重过渡；没有手工顶点权重绘制 |
| 姿态 | 自动／FK／IK 子工具，重置姿态 | 自动保留原有身体／末端和 Shift 手势；显式 FK 始终只转当前骨骼 |
| 权重显示 | 按骨骼颜色显示蒙皮权重 | 仅显示 |
| 骨架管理 | 自动推断、启用和禁用、草稿完成和取消 | 一个工程一套骨架 |
| 采样与动作 | 采样容差、角度间隔、关键形上限、骨骼预设动作 | 属于骨骼面板和动画面板能力 |

## 能力清单：16 项

按结构编辑 8 项、绑定与权重 4 项、姿态 4 项统计。优先级为 P0 5 项、P1 7 项、P2 4 项。当前完成 9/16：全部 8 项结构编辑，以及显式 FK／IK；其余条目待实现。

| 类别 | 工具 | 优先级 | 建议行为 |
| --- | --- | --- | --- |
| 结构 | 多选与变换（已完成） | P0 | 框选、增选，整骨或骨链平移、旋转、缩放，明确相连关节的联动范围 |
| 结构 | 重命名（已完成） | P0 | 修改显示名称，保持 ID、参数和绑定引用稳定 |
| 结构 | 设置／清除父级（已完成） | P0 | 选父骨骼，检查循环，选择保持位置或连接末端 |
| 结构 | 复制骨骼／骨链（已完成） | P1 | 新 ID，保留层级和关节设置，独立参数；选择不绑定或将绑定转移到副本 |
| 结构 | 镜像骨骼／对称编辑（已完成） | P1 | 设置对称轴，镜像坐标、侧别和方向，预览可明确匹配的左右图层数量；保存配对并支持对称关节／变换 |
| 结构 | 细分骨骼（已完成） | P1 | 分成 2–16 节，保留首段 ID、参数和绑定，原子级挂到末段，重烘焙自动权重 |
| 结构 | 融合／溶解骨骼（已完成） | P1 | 合并连接到无分叉肢体父级的子骨骼，延长父骨并迁移网格绑定和子级 |
| 结构 | 连接／断开关节（已完成） | P2 | 保留父级关系，控制端点是否联动；显式连接状态持久化，兼容旧工程的坐标推断 |

| 绑定与权重 | 权重归一化／清理 | P1 | 清理低权重、限制影响骨数量、检查无权重顶点，配合手工权重 |

## 实施顺序

阶段 3：复制、镜像、细分和融合。复制后的语义肢体骨骼使用独立参数；内置身体和头部副本转为自定义骨骼，避免重复内置变形器。镜像按侧别、语义、变体和名称匹配对侧图层，歧义匹配保持未绑定；明确匹配的绑定转移到镜像骨骼。配对和镜像轴持久化，对称编辑支持关节和选区变换。细分保留首段引用，融合将子骨段几何、绑定和后代合并到父级；两者解除受到影响的镜像配对。已添加引用／序列化回归及实际骨骼烘焙的静止网格、参数唯一性验证。

阶段 2：多选、变换与显式 FK／IK。编辑模式支持 Shift 增减选和空白拖拽框选；拖动身体平移选区，工具详情可按选区中心旋转／缩放，可包含后代。外部相连父尾、子头和兄弟头随共享关节同步，断开的端点不参与。自动姿态保留原快捷手势，FK 和 IK 显式覆盖手势。已添加选区跨框、共享端点、骨链不重复变换、旋转缩放和实际 FK／IK 求解回归测试。

阶段 1：重命名、父级和连接状态。骨骼设置中编辑名称并按 Enter 或移出输入框保存；父级下拉默认保持位置，再开启「连接父骨骼末端」将子树平移到父骨末端。断开后即便坐标重合，也不再联动。已添加名称引用稳定、子树平移、防循环、断开及序列化回归测试。

先完成结构操作的选中状态、草稿及撤销语义，再做重命名、父级设置、多选变换和批量绑定。显式 FK／IK 可复用现有姿态求解逻辑。复制、镜像、细分和融合需要同步验证参数 ID、绑定网格与导出；手工权重需要先建立持久化数据和统一的运行时／烘焙读取路径。IK 目标和约束最后加入。
